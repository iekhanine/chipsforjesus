# Chips for Jesus – cartoon redesign

Brand assets: `public/chips-for-jesus-logo.webp` is the illustrated logo displayed in both navigation and hero; `public/chip-feast.webp` is the decorative snack banquet ribbon. Updated favicon and OG preview.

The Vite/React app retains Stripe checkout, account pages, member area, admin and API handlers. No backend logic or database schemas changed.

Commands: `npm ci` then `npm run build`; deploy normally to Vercel. Configure environment variables in your hosting provider. `.env` intentionally excluded from this deliverable because it may contain secrets.
